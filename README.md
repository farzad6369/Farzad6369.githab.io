# World Treasure

بازی مرورگری چندزبانه گنجینه جهانی.

## بخش‌ها

- فرانت‌اند: HTML، CSS و JavaScript
- بک‌اند: Node.js و Express
- پایگاه داده: SQLite
- بات تلگرام
- سیستم جان، امتیاز، رفرال، پرداخت و لیدربورد

## وضعیت پروژه

این مخزن محل نگهداری کد پروژه است. برای اجرای بک‌اند باید پروژه روی یک سرور Node.js مستقر شود.

## امنیت

اطلاعات محرمانه مانند توکن بات تلگرام، رمز مدیر و کلیدهای خصوصی نباید در GitHub قرار بگیرند.
